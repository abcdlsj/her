# Core 层 - 核心业务逻辑

## 模块职责

Core 层包含 Her 的核心业务逻辑，与 UI 和基础设施完全解耦。

## 文件说明

| 文件 | 说明 |
|------|------|
| `agent.py` | Her Agent 主类，处理对话和探索 |
| `intent.py` | 意图识别系统，Her 的"大脑" |
| `memory.py` | 记忆系统，保存对话和探索历史 |
| `tools.py` | 外部工具调用框架（预留扩展） |

## 核心原则

1. **意图驱动**: 所有行为基于意图识别结果
2. **无 UI 依赖**: 通过事件通知状态变化
3. **可测试**: 所有组件可独立测试

# UI 层 - 用户界面

## 模块职责

UI 层负责与用户交互，使用 Textual 实现分栏 TUI。

## 文件说明

| 文件 | 说明 |
|------|------|
| `app.py` | Textual 应用主入口 |
| `panels/intent.py` | 左侧意图面板 |
| `panels/chat.py` | 右侧对话面板 |

## 布局结构

```
┌──────────────────┬────────────────────────────────────┐
│                  │                                    │
│   意图记录面板    │           对话区                    │
│   (25% 宽度)     │          (75% 宽度)                 │
│                  │                                    │
│                  ├────────────────────────────────────┤
│                  │           输入框                    │
└──────────────────┴────────────────────────────────────┘
```

## 核心原则

1. **事件驱动**: 通过订阅事件更新界面
2. **响应式**: 界面随窗口大小自适应
3. **非阻塞**: 输入不阻塞界面更新
